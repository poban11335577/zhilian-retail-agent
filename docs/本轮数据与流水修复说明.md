## 当前Agent实际能力

需求理解 → 模型调度业务工具 → 同一账本查询计算 → 诊断 → 模型行动建议 → 引用和结构检查 → 保存 → 人工审核。数字由程序产生；模型不得写库存或财务。9个角色配置不是9次独立模型推理。证据证明数据出处和计算依据，不证明预测一定正确。

支持中文天数、三成、百分之、下降、负增幅、调整目标和预算；销量/销售额/毛利/毛利率排名；销售价格查询；单商品采购只算该商品行。相对日期锚为当前查询截止日，最终账期会显示。未知商品或冲突/不支持条件应澄清。

生鲜预测比较日均与星期均值，样本足够时末7天留出；原始正向销量参与需求，退货与损耗参与账面库存。参考损耗用于需求换算，包装0.5千克、安全余量0.2日均为情景（拟），分日到货。缺少实测效期及次日验收，次日可售按0保守测算（拟），账面库存另外显示；不能把两者混为库存错误。

总预算按包装严格分配，展示被压缩数量及未满足需求。毛利率优先规则是启发式，不声称全局最优。全店全部79种测算，展示前20，CSV导出全部及所用原表行号。审核保存意见，尚不自动创建默认案例采购、收货或付款；独立企业台账有单独业务流程。

## 可复现演示

1. “小米椒明天备货，需求增长三成，预算500元。” 试运行：账面库存5.4千克（拟），建议25千克（拟）、预算35元（拟）。
2. “那只做3天，下降20%，预算100元呢？” 沿用商品并改条件；试运行分配69千克（拟）、96.6元（拟），剩余需求和分日计划明确显示。
3. “销量最高的五种菜是什么？” 按原始正向千克销量排名，不拿销售额代替。
4. “小米椒多少钱一千克？” 区分原始售价和拟定采购成本。
5. “9月5日至15日利润和现金为什么不同？” 用同一期利润、资本、往来和库存变动解释现金调节。
6. 打开原表依据、完整Excel与后台同一报告，再审核方案。
