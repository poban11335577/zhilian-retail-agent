# 2026年10月1日对话工作台改版

本轮根据用户决定仅上传 GitHub，未发布到 Netlify 正式站点。新版代码以公开仓库为准，原网址仍为旧版。

首页改为独立经营对话界面，输入框在首屏，聊天记录按时间顺序排列。
电脑显示左侧导航、中央对话和宽屏数据依据栏；手机使用导航抽屉和单列对话。
可从四个经营场景填入问题、按回车发送、停止分析、继续未完成任务、开始新会话。
查询账期可以切换；每条报告保留当时的账期，不用新的筛选日期改写历史结果。
进度来自真实任务阶段，结果支持复制、回查台账和导出测算明细。
财务卡片与利润到现金调节表直接读取后端工具结果，未新增一套金额公式。
多商品测算先展示3项，其余可以展开；导出保留后台提供的全部分配结果。

首页只读取轻量账套概览，不先下载约10MB的两份原账套。
概览在构建时由同一经营计算入口生成；经营数据页仍按需读取完整明细。

## 已验证

- TypeScript 类型检查通过，39项经营与智能体回归测试全部通过，生产构建成功。
- 本地浏览器检查 390×844、375×667、320×568、390×460、768×1024、1440×900 六种尺寸。
- 输入框全部在当前视口内，页面宽度无横向溢出；长表格在自身容器内滚动。
- 手机菜单、问题发送、财务结果、新会话及刷新后的会话恢复已检查。
- 屏幕尺寸测试使用浏览器模拟，不等同于手机真机输入法或软键盘测试。

## 仍需完善

样式与阅读体验改进不代表智能体已完成全部业务执行闭环。
当前公开案例的采购审核保存方案意见；真实下单、入库、付款仍需独立登记。
参赛前还需扩展问答评测、核验异常恢复和真机键盘体验。
数据来源和“（拟）”边界保持明确，不能宣称拟定流水是真实门店单据。
