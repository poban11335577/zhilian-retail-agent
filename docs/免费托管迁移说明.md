# 免费托管迁移说明

该项目是个人参赛演示，部署使用 Vercel Hobby 免费方案，持久化状态使用 **Private Vercel Blob**。原始销售、演示台账、全部页面及导出文件继续来自公开仓库；对话、后台配置、企业访问凭证、加密后的模型密钥及用量记录仅存放在私有存储。

## 部署配置

1. 用自己的 GitHub 账号登录 Vercel，选择 Hobby 个人免费方案。
2. 导入 `poban11335577/zhilian-retail-agent`，Framework 为 Vite，Node.js 24。仓库里的 `vercel.json` 已指定构建命令、香港函数区域、60 秒函数上限及页面路由。
3. 创建 **Private** Blob store 并连接该项目 Production 环境；SDK 自动使用 Vercel 配置的 OIDC。不能选 Public store，也不要把密钥放进前端变量。
4. 在服务端配置 `ADMIN_PASSWORD_HASH` 和 `SESSION_SECRET`。本地配置见 `.env.example`；首次本地安装执行 `node scripts/setup.mjs`。迁移时沿用旧站的服务器加密密钥，才能读取已有加密配置。
5. 导入原后台配置与累计模型用量后再开放模型，预算仍为累计 450,000 tokens；迁移不代表模型额度重新开始计算。

Vercel 的构建命令是 `npm run build:web`，不会运行旧托管平台的发布命令。API 入口为 `api/[...path].ts`，复用原 `createAPI`。适配器 `server/vercel-repository.ts` 使用私有、绕过缓存的读取、ETag 条件更新、禁止覆盖的首次创建和完整分页，避免跨实例覆盖额度及会话。

## 免费额度边界

Hobby 仅适用于个人非商业项目。Vercel Blob 当前免费额度为每月 1 GB 存储、10,000 次简单操作、2,000 次高级操作、10 GB 数据传输。超额时服务受限，不会自动产生额外账单；不要为了继续运行而点击 Pro 试用或添加付费服务。对话执行会产生多次存储写入，免费不是无限使用。

模型供应商的 tokens 额度和网站托管额度是两回事。上线验收需检查首页、深层链接、真实 API、后台登录、会话持久化、连续追问、模型额度及 Excel 导出。迁移前后不要同时开放同一模型密钥却使用互不共享的累计额度记录。
