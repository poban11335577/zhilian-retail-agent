# 目标经营智能体版本说明

本版本用于参赛演示。入口为首页经营对话和 `/growth` 目标工作台。

## 本次四项改动

1. **目标驱动规划**：从全店净利润目标出发，读取历史销售并自动比较“保持当前条件”“优先降低损耗”“销量与降损配合”。程序在当前条件上搜索额外销量提升，优先选择按条件达到目标且需要较少销量增长的方案；无法达到时展示缺口。没有全局最优或必然达标保证。
2. **备货与利润联动**：商品需求共用 `lib/stock-forecast.ts`，成本、包装、库存、参考损耗及原表行号共用同一账套。采购按日期和商品分配；预算不足时减少可支持销量，再计算销售净额、净售成本、报损成本及净利润。采购支出已进入净售和报损成本，不重复扣减。
3. **连续追问**：服务端保存明确的目标、周期、采购预算、销量、售价、成本、降损和其他费用条件。追问只覆盖提到的字段。支持预算减半/翻倍、只调整损耗、保留其他条件、采用上一轮第二个或指定名称方案。独立新问题和新会话会重置条件。
4. **中文报告和 Excel**：网页和问答结果均可下载中文 HTML 报告，打开后可打印或保存 PDF。Excel 有五张表：方案总览、方案比较、商品备货、分日流水、数据与口径。导出时可选择不同方案，完整展示全部商品和日期，不只导出当前屏幕预览的几行。

## 同源计算

逻辑为：原表正向销量 → 日均/星期分组模型 → 未来分日需求 → 参考损耗、安全余量与包装 → 预算分配 → 可支持销量 → 销售净额与成本 → 净利润和目标缺口。

基线含 24,040 笔原始销售、79 种商品及来源 SHA256。6 项历史台账对账保留；每个未来方案另核验 5 项供销利润关系。全部金额以人民币万分之一元整数计算，数量以克整数计算；表格保留 4 位金额精度，中文报告显示 2 位金额可能有展示尾差。

生鲜账面库存缺少批次效期和次日验收，因此未来可售按 0 测算。分日到货后，净售之外的数量按当日清理报损（拟）。这能避免凭空将无法证明可售的库存计入未来销售。

累计采购预算是整个预测周期的采购总额上限。先按比例覆盖商品与日期，再按单位贡献分配剩余包装；预算压缩同时可能减少报损，采购更多不代表利润一定更高。此规则不证明全局最优。供应商真实交期、产能和现金循环仍需单据确认。

历史费用整体变动的旧情景计算保留在“原费用情景与预测边界”，用于解释历史口径，与逐商品分日方案明确分开。历史基线利润不应直接等同于未来采购计划利润。

## 建议演示问题

```text
未来30天全店目标净利润10000元，采购预算60000元。帮我比较经营方案，核对备货和利润。
那预算减半
只改损耗，损耗降低30%
保留其他条件，销量改10%
采用第二个方案，预算翻倍
```

程序追踪实际执行的读取、需求测算、方案比较、预算检查、利润复算步骤。模型只解释和调度；业务数字来自工具。模型审核只接收精简的方案汇总，避免把数千条未来明细重复发送而浪费额度。

## 开发与协作

沿用 README 的 Node 24 环境，执行：

```text
npm ci
npm test
npm run build
npm run dev
```

无 API Key 时可以演示确定性目标规划和全部导出。实际模型接入沿用服务端配置及累计 450,000 tokens 上限。密钥、后台密码和本地会话不在公开源码中。

利润 Skill 的条件 JSON 新增 `budget_scaled`（元×10000；null 表示未设累计上限）。脚本返回 `planning` 字段：

```text
node skills/profit-forecast/scripts/forecast.mjs conditions.json
```

Excel 为导出时的测算快照。净利润、贡献毛利和总览引用用简单公式便于核对；修改复杂经营条件请回到工作台重新测算，Excel 不承诺自动重新分配采购预算。格式模板由 Artifact Tool 制作；运行时填充同一报告结构，不增加服务器依赖。

## 数据与效果边界

历史销售数量和单价有公开原始来源；收入为数量乘单价的演算。演示日期、采购、库存、供货关系、成本费用及全部未来方案（拟）。拟定成本不能认定为原商超真实利润。

销量提升和降损是待验证条件；不能将它们说成已经实现的增长、模型发现的因果关系或成功率。当前搜索上限为在用户销量变化上额外增加 30 个百分点，且不超过 100% 总变化。没有价格弹性、节假日、税费、阶梯人力、新增活动费用或真实产能模型。

本版新增针对预算、分日库存/成本、原备货一致性、连续追问、模型审核载荷和导出一致性的回归测试。实际豆包批量口语评测安排在后续版本。

本次 49 项回归测试和类型检查通过，客户端及后端构建通过。Excel 五张工作表已渲染，跨表引用及修改输入后的简单利润公式重算已核验。浏览器工具被已保存的本地地址拒绝权限拦截，因此本轮新的手机、电脑页面截图验收尚未完成；原有截图属于上一版。
